#+TITLE: Globe lineation: the witness-page pipeline
#+DATE: 2026-10-07
#+OPTIONS: toc:nil num:nil

* What this is

Perseus's P4 TEI encoding of the Globe Shakespeare was generated from
files produced via the double-keyboard method from a copy of the Globe
Shakespeare in the Tisch Library at Tufts. The printed text includes
intermittent marginal lineation, which was encoded variously as =n= 
attributes on =<l>= and =<lb>= elements. Supporting Canonical Text
Services requires accurate resolution of line numbers; the vagaries of
the printed layout made simple extrapolation of line numbers impossible.

=src/globe/= regenerates a play's Globe Shakespeare line numbering from
page images of the printed Globe, and writes the play's Globe edition
for canonical-engLit. It was developed in =globe-lineation-workshop=
and moved here unchanged except in imports and paths; the workshop is
frozen at its tag =v1.0= as the record of how it was built (see
[[*References to the workshop]]).

* The method

Words and structure come from the P4 (=Renaissance/Shakespeare/opensource/=
in canonical-engLit, read-only), converted to P5 by =p4_convert.py=.
Line starts come from the page:

1. Each printed page is read from a witness's Kraken ALTO
   (=page_rows.py=). Columns are split at the empty gutter, and a
   column's margin is the leftmost cluster of at least four flush
   rows. Rows are classified by their offset from the column margin,
   in units of row pitch: start, turnover, indented,
   displaced. The page's own marginal numbers are taken off and
   attached to the last row of their line.
2. The rows are aligned to the P4's words (=align_play.py=,
   =tokens.py=), so every row knows the word it starts at.
3. A Globe line is a start-band row carrying speech plus every turnover
   or displaced row after it (=lineate.py=). Lines are counted from
   each scene's start, across page breaks.
4. The P5 is written with a =<milestone unit="line" ed="Globe" n=…/>=
   at the start of every Globe line and an =<lb/>= at every other
   printed row (=emit_tei.py=), under the existing P5's header,
   rewritten (=tei_header.py=).

Two witnesses, both 1,054 leaves, OCR'd whole: =miun= (Michigan, 1866)
and =trent= (Trent, 1887). They share plates, so either is authoritative
for line breaks. Page by page, =miun= is tried first and =trent= if
=miun= does not close (=regenerate.ORDER=); where both fail on an
interval from a number on the page before, that page is built again
from the other witness. Their provenance is in
=doc/witnesses.org=.

* The gate

The printed marginal numbers number nothing; they are the check. Every
printed number must equal the count of its line, counted from the scene
start. If any page fails, the play is not written; the reports are, so
the failures can be read. Lear: 32/32 pages, 0 failing intervals,
3,332 Globe lines. Antony: 33/33 pages, 3,063 Globe lines. Titus:
24/24 pages, 2,523 Globe lines. Richard II: 26/26 pages, 2,756 Globe
lines.

Regeneration moves no words: the output's word stream must equal the
P4's, or the build stops.

* The tables (=data/globe/=)

| Table                  | What it says                                                     | Who changes it                       |
|------------------------+------------------------------------------------------------------+--------------------------------------|
| =plays.tsv=            | each play's P4 source, published edition, first and last printed page, and DraCor file | when a play is added (=plays.py=) |
| =witnesses.toml=       | where each witness's scans and OCR layers are, under =GLOBE_WITNESSES= | when a witness is added or moved |
| =leaves-miun.tsv=, =leaves-trent.tsv= | leaf -> printed page, with the basis of each row  | reviewed; built by the workshop's =build_leaf_tables.py= |
| =witness-offsets.tsv=  | the running-head audit's offsets per witness; the source of the leaf tables, not read by the build | as above |
| =shared-lines.tsv=     | junctions the page cannot show -- folded (=shared=, =turnover=) or cut (=separate=) --, numerals both witnesses misread (=numeral=) or the page sets beside the next line (=misplaced=), lines the page prints without words (=lacuna=), and two printed lines the Globe gives one number by its own slip (=miscount=), each row naming its play and one of its pages | rows proposed by the build or from the Folger; =checked= is filled by Cliff, after looking at the page image |
| =numeral-checks.tsv=  | each margin numeral the build took from the other witness, because the first witness's reading did not close the count: play, page, the line's first words, both readings | rows proposed from the =regenerate-PLAY-numerals.tsv= report; =checked= is filled by Cliff, after looking at the page image |
| =witness-manifest.tsv= | sha256 of every witness file the build reads, per play, and of the play's DraCor file with its commit | =globe-lineation manifest PLAY=, deliberately |

*=checked= is Cliff's.* The canonical build refuses to use a
=shared-lines.tsv= row whose =checked= is empty; the review build is
still written (=--allow-pending= overrides, for development only).

*So is every re-read numeral.* Where one witness's margin numeral does
not close the count and the other's does, the build takes the other's
(=number_page=). Both readings are OCR, and Kraken reads margin numerals
badly, so the canonical build also refuses while any re-read has no
checked row in =numeral-checks.tsv= (=src/globe/numeral_checks.py=). A
re-read changes no output; the check decides only whether the canonical
build is written. Rows are matched on play, page, the line's first words
and both readings; a row no re-read matches is reported when the play is
built. The 66 re-reads in the eighteen plays published before the rule
(2026-10-22) were proposed unchecked, so until Cliff checks them those
plays verify only with =--allow-pending=.

*A row is tried in each witness.* A row that does not apply in a witness
(its words are not on that witness's lines) rules the witness out for
the page, and the next is tried; the gate report shows it as
=witness:table=. Only a row that applies in no witness stops the build.

*The manifest pins the witnesses.* The build refuses a leaf (or leaf
table) that is not in =witness-manifest.tsv= or whose sha256 differs.
Rewriting a play's rows is how a deliberate change to a witness is
recorded.

*And the play's ShakeDraCor file.* Its row (witness =dracor=) holds the
file's sha256 and, in =catalog=, the clone's commit and the play's
DraCor id as they were when the row was written; a file that differs
from the clone's commit cannot be pinned. The build refuses the file if
it is there and its sha256 differs, and refuses a play with no such
row: the header's Folger citation is written from it, so the commit the
edition names is the commit of the bytes the build checked. Lear is
pinned at =c34c2d4=, the commit its published header already named.

* The two builds and the reports

- Canonical: =out/globe/PLAY/shakespeare.PLAY.globe.xml=. Not tracked
  here: its home is canonical-engLit, where it is copied to publish.
- Review: =shakespeare.PLAY.globe.review.xml=, the canonical with XML
  comments for a reader checking it against the page: each page's
  witness and leaf, where one witness was taken over the other, each
  =shared-lines.tsv= row applied, and the rows the reports flag (word
  disagreements, P4 anchors, verse/prose, borderline rows). Tracked.
  Stripping the comments must give the canonical bytes, or the build
  stops.
- Reports: =reports/globe/regenerate-PLAY-*.tsv= (gate, intervals, word
  disagreements, old-vs-new P4 anchors, verse/prose, borderline rows,
  Folger check, @part against the page, re-read numerals with each
  witness's leaf and their check status), and the Schmidt smoke test,
  =schmidt-smoke-PLAY.{tsv,md}=, which records the edition's sha256.

*Schmidt is a standing check.* Every build regenerate writes is checked
against Schmidt's citations of the play (=schmidt_smoke.py=): does the
cited line hold his quotation, or his headword? It reports and never
gates (Schmidt has his own slips: Lear passes 94.6%, Antony 93.9%). Its
report opens with *runs*: three or more citations in a row, in one
scene, off by the same amount, which is where our count and the Globe's
part and by how much (Antony II.7 ran +5 from 69 to 118 before its table
rows). The citations and quotations are the schmidt-lexicon-workshop's
=out/citations.tsv= and =out/citation_quotes.tsv=, every play's since
its =quotes/corpus-wide= branch; without them the check is skipped, and
the build says so.

Each build carries a stamp in =<revisionDesc>=: the tool, its version,
the corpus-tools commit, and the sha256 of the P4, =shared-lines.tsv=
and the edition template.

*An edition is built from sources.* Its header starts from
=data/globe/edition-template.xml=, filled with the play's title and CTS
URN (=emit_tei.shell=); the build writes the rest of the header
(=tei_header.py=) and the body from the P4. It never reads the
published edition, which until <2026-10-09> was the shell of its own
next build (canonical-engLit =doc/agenda.org= =#globe/shell-template=).

* Running it

Inputs, as siblings of this repository:
- =../canonical-engLit=, with =mvp= checked out (the build refuses
  otherwise: the P4 is read from its working tree);
- the witnesses: the =PerseusDLCode/globe-witnesses= repository, at
  =$GLOBE_WITNESSES= (default =../globe-witnesses=; =doc/witnesses.org=);
- =../schmidt-lexicon-workshop/out/= for the Schmidt check (every play's
  quotations: the workshop's =quotes/corpus-wide= branch);
- the ShakeDraCor clone at =$SHAKEDRACOR= (default =../../shakedracor=,
  beside the =PerseusDLCode= directory), for the play's Folger file named
  in =plays.tsv=: the Folger report only. If the clone is absent the
  report is skipped, and the build says so; if the file is there, it
  must be as =witness-manifest.tsv= pins it.

#+begin_src sh
make globe-verify PLAY=lr      # build to a temp dir; equal to the published file, stamp aside?
make globe-regenerate PLAY=lr  # write out/globe/lr and reports/globe; refuses on a dirty tree
.venv/bin/globe-lineation smoke lr       # Schmidt's Lear citations against out/globe/lr (regenerate runs it too)
.venv/bin/globe-lineation manifest lr    # re-pin the witness files and the DraCor file the build reads
.venv/bin/globe-lineation regenerate lr --scratch=DIR   # a development build, anywhere
#+end_src

*Verify* is the fixed-point check: built from its sources, the play
must equal its published file byte for byte, except the stamp's
=<change>= (its date, commit and sources' sha256s).

*Regenerate refuses a dirty tree* rather than stamp a commit that does
not describe the code. A rebuild that changes nothing still changes the
review build's stamp, so commit or discard it.

Serialisation is what byte identity tests: lxml is locked at 6.1.3
(libxml2 2.14.6), as it was in the workshop.

* Adding a play

A play is a row in =data/globe/plays.tsv=: its P4 source and its
published edition (both relative to canonical-engLit), its first and last
printed page, and its file in the ShakeDraCor clone. Lear and Antony have rows.
A play also needs its rows in =witness-manifest.tsv=
(=globe-lineation manifest PLAY=, which pins its DraCor file too and
so needs the clone), its shared lines reviewed into
=shared-lines.tsv=, its re-read numerals checked in =numeral-checks.tsv=,
and its title and copy-text in =tei_header.py=
(=PLAY_TITLES=, =COPY_TEXT=), which the table does not yet hold.
